依据期刊 Guide for Authors 及编辑部格式筛查要点整理。

## 必传文件（Editorial Manager）

| 文件 | 说明 |
|------|------|
| `paper/JHRS_Potomac_upstream_streamflow_forecasting.docx` | **主稿**（单栏、双倍行距、连续行号、结构化摘要、作者–年份引用） |

## 主稿格式合规对照

| 要求 | 状态 |
|------|------|
| 结构化摘要三段：Study region / Study focus / New hydrological insights for the region | ✓ |
| Highlights 3–5 条，每条 ≤85 字符 | ✓（另有独立文件） |
| 双倍行距 + 连续行号 | ✓ |
| 单栏 Word | ✓ |
| 正文作者–年份引用（非数字角标） | ✓ |
| 建议结构：Intro → Materials and methods → Results → Discussion → Conclusions | ✓ |
| Conclusions ≥3 段（发现/新颖性；更广影响；局限与展望） | ✓ |
| CRediT、利益冲突、Funding、Data availability | ✓ |
| Declaration of generative AI… | ✓ |
| Keywords（≤7） | ✓ |

## 提交前你必须改的

1. 真实作者姓名、单位、通讯邮箱  
2. CRediT 角色与 Funding 基金号  
3. 若未使用 AI 辅助语言润色，把 GenAI 声明改为 “The authors declare that they did not use generative AI…”  

## 不要当主稿交的

- 旧中文稿 / `manuscript.tex`  
- 仅内部用的 `results/*.json`（可作为补充材料）
